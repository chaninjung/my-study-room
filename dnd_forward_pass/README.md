# 순전파(forward pass) 애니메이션 — DND Week 6 (MLP)

Lecture 6(다층 퍼셉트론, MLP)의 순전파를 **눈으로 따라갈 수 있게** 만든 자료입니다.
강의 화면에 나오던

```
앞 층에서 온 값  →  × 가중치 w  →  전부 더한 값 z  →  활성화 함수  →  최종 답
```

이 흐름을 **입력 6개, 은닉층 5개(가중치 214개)** 규모로 실제로 돌려 봅니다.
입력은 그냥 아무 숫자가 아니라 **Week 6 실습에서 쓴 Palmer Penguins 의 실제 측정값**이라,
"실제 데이터가 들어가서 실제 결과가 나오는" 과정을 볼 수 있습니다.

## 2. 이 자료가 보여 주는 것

```
입력층        은닉층 1   은닉층 2   은닉층 3   은닉층 4   은닉층 5   출력층
x1 .. x6  →  h1_1..8  →  h2_1..8  →  h3_1..6  →  h4_1..5  →  h5_1..4  →  y_hat
              ReLU       ReLU       tanh       tanh       tanh       Sigmoid
```

* 화살표 하나하나가 **가중치 w** 입니다 (총 214개). 계산 중인 뉴런으로 들어오는 화살표만 밝게 표시되고,
  그 위에 `× 1.23` 처럼 가중치 값이 붙습니다.
* 파란 원은 **편향항**(항상 1)이고, 그 값 `b` 도 마지막에 더해집니다.
* 노란 원이 **출력**입니다. Sigmoid 를 지나므로 0~1 사이 = "Gentoo 종일 확률"이 됩니다.
* 오른쪽 패널은 강의 화면과 같은 순서로 계산을 보여 줍니다:

| 단계 | 내용 | 하는 일 |
|---|---|---|
| 1단계 | 입력 | `x1..x6` 6개 숫자가 들어옴 |
| 2단계 | `× w` | 앞 층에서 온 값에 가중치를 곱함 (`a × w`) |
| 3단계 | 전부 더하기 | 곱한 값 + 편향 = **z** |
| 4단계 | 활성화 | `a = ReLU(z)`, `a = tanh(z)` … |
| 5단계 | Sigmoid | 마지막 층이면 `Sigmoid(z)` = 0~1 확률 = **최종 답** |

수식으로는 Lecture 6 과 완전히 같습니다.

```
z = W a + b          (전부 더한 값)
a = g(z)             (활성화 함수. 은닉층에서는 비선형 함수가 꼭 필요)
y_hat = Sigmoid(z)   (마지막 층. 이진 분류라서 Sigmoid)
```

## 3. 데이터 (입력 6개가 무엇인지)

Week 6 실습과 **같은 CSV**(Palmer Penguins)에서 결측치가 없는 333마리를 썼습니다.

| 입력 | 내용 | 표준화 |
|---|---|---|
| x1 | 부리 길이 (mm) | `(값 - 평균) / 표준편차` |
| x2 | 부리 깊이 (mm) | 〃 |
| x3 | 날개 길이 (mm) | 〃 |
| x4 | 몸무게 (g) | 〃 |
| x5 | 성별 (수컷 1 / 암컷 0) | 〃 |
| x6 | 부리 비율 (길이 ÷ 깊이) | 〃 |

* 정답(label)은 **Gentoo 종이면 1, 아니면 0** 입니다.
* 표준화를 하는 이유: 몸무게(4000)와 성별(0/1)처럼 단위가 다른 값을 그대로 넣으면 학습이 잘 안 됩니다.
  그래서 모든 입력을 "평균에서 얼마나 떨어져 있는지"로 바꿔 넣습니다.
* 실제 예시: 부리 46.1mm · 부리깊이 13.2mm · 날개 211mm · 몸무게 4500g · 암컷 인 Gentoo 펭귄 →
  `x = [+0.386, -2.016, +0.717, +0.364, -1.009, +1.789]` → **Gentoo 일 확률 98.38 %**

학습은 Lecture 6 에 나온 그대로 **Batch gradient descent + binary cross-entropy** 로 했습니다
(정확도 99.7 %). 학습된 가중치는 `network.json` 에 저장되어 있어서 애니메이션은 계산만 합니다.

## 6. 자주 헷갈리는 점

* **0.000 이 자주 보이는 건 정상입니다.** ReLU 는 음수를 0 으로 만드는 함수라서,
  "이 입력은 이 뉴런을 통과하지 못했다"는 뜻입니다. (tanh 층은 0 이 잘 안 나옵니다)
* **가중치는 어디서 왔나?** `train_network.py` 가 333마리 데이터로 학습시킨 값입니다.
  사람이 정한 게 아니라 gradient descent 가 찾은 값입니다.
* **왜 확률인가?** 마지막 활성화 함수가 Sigmoid 라서 출력이 0~1 사이로 눌립니다.
  0.5 이상이면 "Gentoo", 미만이면 "Gentoo 아님"으로 판정합니다.
* **z 와 a 의 차이?** `z` 는 그냥 더한 값(활성화 전), `a` 는 활성화 함수를 통과한 값입니다.
  화면에서 뉴런 안의 숫자가 계산 중에는 z(연보라)였다가, 4단계가 끝나면 a 로 바뀝니다.
* **보기 방식 3가지**: `가중치 하나씩`(제일 자세히, 324단계) / `뉴런 하나씩`(기본, 110단계) /
  `층 하나씩`(빠르게, 14단계).
* **뒤로 가기도 됩니다.** `←` 를 누르면 이전 단계로 돌아가서 다시 볼 수 있습니다.
