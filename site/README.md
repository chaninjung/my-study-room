# My Study Room — ELTE AI & Computer Science Study Hub

A study site for **ELTE (Eötvös Loránd University)** AI & Computer Science students. Deployed on GitHub Pages — open from phone, tablet, or laptop at the same address.

## Why this site exists

From **2026 Autumn**, ELTE Computer Science course content is available here so students can study for **preliminary exams** through practice questions.

- **Who can join:** Only users with an **`@inf.elte.hu`** email address can sign up. Anyone can find this site through Google (search: **inf.elte.hu**), but only ELTE inf accounts can create an account and log in.
- **Current courses:** **Deep Network Development (DND)** — one course for now, more will be added.
- **Purpose:** Practice with exam-style questions and take mock exams to prepare for the real ELTE exam.

## How to use

- **Online**: https://chaninjung.github.io/my-study-room/ — just type the address
- **Offline**: open `index.html` in your browser (no server needed)

## ⚠️ Professor's materials are NOT included

This site contains only student-written practice questions based on lecture slides and public example questions. It does not include lecture slide PDFs, example question documents, or any original professor materials.
