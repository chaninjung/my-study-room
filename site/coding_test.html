시작 방법

  1. 새 notebook을 만들고 Kernel을 restart합니다.
  2. 필요한 import와 seed를 직접 작성합니다.
  3. A부터 I까지 처음부터 실행합니다.
  4. 마지막에 tester와 전체 재실행으로 확인합니다.

구현 과제

Part A — Dataset loading
  • 세미콜론 CSV를 읽어 header를 제외한 dataset_noisy를 만듭니다.
  • np.ndarray, np.float32, sample별 행을 사용합니다.
  • 빈 필드는 np.nan이어야 하며 shape와 결측 위치를 확인합니다.
Part B — Missing values and indicators
  • 결측 가능 열 세 개에 대해 indicator 열을 만듭니다.
  • 원본 열은 유지하고 indicator 세 개는 배열 마지막에 붙입니다.
  • 결측값은 0으로 대체하고 최종 배열에는 NaN이 없어야 합니다.
Part C — Data split
  • dataset_split_train, dataset_split_val, dataset_split_test를 만듭니다.
  • 약 50%/25%/25%로 무작위 분할하며 sample 중복이나 누락이 없어야 합니다.
  • 재현 가능한 결과를 위해 seed를 사용할 수 있습니다.
Part D — Regression DataLoader
  • dataloader_reg_train, dataloader_reg_val, dataloader_reg_test를 만듭니다.
  • input은 float32 2차원, label은 float32 (batch_size, 1)입니다.
  • train/validation은 shuffle, test는 순서를 유지하고 label 열은 input에서 제외합니다.
Part E — Regression model
  • torch.nn.Module 기반 reg_model을 만듭니다.
  • Linear 3개, hidden size 25·25, output size 1, hidden 뒤 ReLU를 사용합니다.
  • output shape은 (batch_size, 1)이어야 합니다.
Part F — Regression training and evaluation
  • MSE와 gradient-based optimizer로 학습하고 epoch별 train/validation loss를 기록합니다.
  • 두 loss curve를 그리고 test_mse와 sample prediction을 저장합니다.
  • validation/test를 optimizer update에 사용하지 않고, test는 최종 평가에만 사용합니다.
Part G — Classification labels and DataLoader
  • 세 성적 중 낮은 값이 둘 이상이면 낮은 성취, 아니고 평균이 기준값 미만이면 중간, 나머지는 높은 성취로 분류합니다.
  • label을 0·1·2로 만들고 classification DataLoader 세 개를 구성합니다.
  • input은 float32 2차원, label은 int64 1차원이며 성적 열은 input에서 제외합니다.
Part H — Classification model
  • cl_model은 Linear 3개, hidden size 30·20, output size 3입니다.
  • hidden 뒤 ReLU를 사용하며 마지막은 raw logits를 반환합니다.
  • CrossEntropyLoss를 사용하므로 모델 안에 softmax를 넣지 않습니다.
Part I — Classification training and evaluation
  • cross entropy로 학습하고 train/validation loss를 기록합니다.
  • early stopping 후 best validation weight를 복원합니다.
  • test_ce, test_acc, true 행·predicted 열의 3×3 confusion matrix를 작성하고 plot합니다.
